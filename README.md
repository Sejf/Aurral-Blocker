# Aurral Blocker for Nicotine+

Automatically block Aurral users from downloading your shares.  

---

## Installation:

Either clone the project using Git or download the latest release and extract it into the following Nicotine+ plugins folder:

### Linux:
`~/.config/nicotine/plugins/`

### Flatpak:
`~/.var/app/org.nicotine_plus.Nicotine/data/nicotine/plugins/`

### Windows:

`%APPDATA%\nicotine\plugins\`
